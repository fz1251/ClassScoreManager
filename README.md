# 班级积分管理系统

一个用来记录和统计班级积分的 Windows 桌面工具。所有数据保存在单个 `.cls` 文件里，打包后免安装，拷到 U 盘就能带走。

## 主要功能

- **学生与小组**：把学生名单按行粘贴进来就能建班，之后可以随时追加；姓名、小组号能在表格里直接改，学生行也能拖着调整顺序。小组管理页用卡片拖放分组：拖进小组容器即入组，拖到左侧面板则取消分组，组内顺序同样拖一拖就能排。
- **积分记录**：一条记录就是表格里的一列分数。保存前是草稿，保存后进入历史，可以随时查看、导出或删除。单元格里可以直接写算式，比如 `+2-1` 会自动算出 1。
- **积分模板**：把常用的分值存成模板（例如"作业未交 -2"），新建记录时套用一套，模板分值和手填分值相加就是本次成绩。已保存的记录不受模板后续改动影响；一条记录只能应用一个模板，后选的覆盖先选的。
- **求和导出**：在积分记录页勾选若干条记录求和，按个人或小组、按学号 / 总分 / 组号排序，导出一份独立的 HTML 表格。用浏览器打开即可，不依赖本程序。
- **界面**：整体 Fluent 风格，左侧导航在班级信息、小组管理、积分记录、积分模板四个页面之间切换；班级信息页右侧是可折叠的操作侧栏，包含学生搜索、记录与模板的查看导航。操作结果和警告以窗口内的通知条提示，不会打断手头的操作。

## 使用要点

1. 打开或新建一个 `.cls` 文件，之后所有内容都写进这个文件。
2. 新建班级时粘贴学生名单（一行一个），也可以直接从表格里复制一列姓名。
3. 要记分时先点「新建积分记录」，表格会出现「积分(当前)」列；填完分值再点「保存积分记录」，记录名不能和已有的重复。
4. 侧栏「表格选项」里可以开关拖动排序、姓名编辑和小组信息编辑，三项默认都是打开的。
5. 保存文件是手动操作（`Ctrl+S`），程序没有自动保存，关闭前记得保存。

## 构建

C++17 + Qt Widgets（不使用 QML），CMake + Ninja 构建，界面全部由代码生成，没有 `.ui` 文件。

需要 MSVC 2022 x64、CMake 3.16+、Ninja，以及 Qt 5.15.19（qtbase + qtsvg，MSVC 2022 x64）。开发时用的是自编译的 Qt，路径写在 `CMakePresets.json` 的 `CMAKE_PREFIX_PATH` 里。

```
cmake --preset qt5-msvc2022-debug
cmake --build --preset qt5-msvc2022-debug
```

换成 `qt5-msvc2022-release` 就是 Release。产物在对应构建目录的 `bin/` 下，运行时需要把 Qt 的 `bin` 目录加进 `PATH`。
