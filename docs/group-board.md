# 小组管理页：配色、落点判定与重排动画

> 本文记录小组管理页（`src/pages/GroupBoardPage`）内部几个机制的当前做法与取舍：组色怎么取、拖放落点怎么判、重排怎么做动画、拖动周边的手感怎么给。
> 涉及文件：`src/widgets/CardStyle.*`、`DragAutoScroller.*`、`FlowLayout.*`、`GroupCard.*`、`StudentCard.*`、`UngroupedPanel.*`。
> 协作规则见根目录 `CLAUDE.md`，项目技术栈见 [project-context.md](project-context.md)。

## 1. 组色：由组号决定

唯一入口 `CardStyle::groupColor(qint32 groupNumber)`：同一组号恒定同色，界面各处都从这里取色。

- 在 OKLCH 取点再转 sRGB：固定明度、彩度上限、起始色相，组号每 +1 色相前进黄金角 137.507764°（= 360°/φ²）。
- 取到的颜色若超出 sRGB 色域，就**二分压低彩度**（16 步）而不是截断 RGB 通道——截断会让颜色发灰偏色。
- 参数依据：46 个真实马卡龙色值的 OKLCH 统计——明度中位 0.870、彩度中位 0.058、75% 分位 0.073。
- 不用"等分 12 槽色相"的原因：第 13 组会与第 1 组同色，且相邻组色差只有黄金角方案的约 1/3；黄金角保证任意组数下相邻组的色相都离得最远。

| 项 | 取值 |
| --- | --- |
| 明度 L | 0.87 |
| 彩度上限 | 0.085（超出色域时按色域二分压低） |
| 起始色相（第 1 组） | 231.5°（浅蓝 `#9fdeff`） |
| 色相步长 | 137.507764° |
| 色域二分步数 | 16 |

用色：组容器底色 = `mix(palette().base(), 组色, 0.24)`，拖拽落入时 0.38；描边 = `mix(黑 α30, 组色, 0.45)`，落入时满色；组内学生卡片直接用组色本体（`CardHost::cardColor()`）；未分组面板的学生卡片用 `palette().base()`，悬停向白混 35%；左栏栏面用 `palette().window()`，与其余界面同底。

## 2. 落点判定：先按 y 选行，行内只看 x

入口是 `GroupCard::dropIndexAt(pos)`，返回插入下标（按不含占位槽的子项顺序）：

1. **参考行**：把各子项的**可见范围**（布局矩形去掉四周 4px 悬停留白）按 y 汇总成行。光标在某行的可见范围内就取那一行；光标还在**已提交行**（占位槽当前所在行）上下各一个"行间留白"（12px）内就留在原行，这是纵向迟滞；都没有命中时取纵向最近的一行（在卡片区之上即第一行、之下即最后一行）。
2. **行内横坐标**：找第一张"判定线在光标右侧"的卡片，插到它前面。判定线 = 卡片中心 ± 6px，往左还是往右取决于已提交的插入点在这张卡片之前还是之后，这是横向迟滞。
3. **下标换算**：隐藏项（被拖动的卡片）没有排布结果，但仍占一个插入下标；占位槽自身不参与计数。

三个关键取舍：

- **判定用布局算出的目标矩形，而不是子项当前的 `geometry()`**：后者在重排动画途中一直漂移，光标停在一格范围内会让落点反复翻转。
- **目标矩形从布局缓存里取**：`QLayout::geometry()` 在布局被 `invalidate()` 之后、下一次激活之前会读到 `(0,0,0,0)`，用它算会把每张卡片判成单独一行，落点直接算到第一行去。`FlowLayout` 因此自己记住最后一次有效的布局矩形（`m_layoutRect`）。
- **横向粘滞是刻意保留的**：占位槽本身占着一格，判定线落在"被推开的"卡片中心上，所以前进/后退的换位线天然差一格。

## 3. 重排动画：弹簧积分

`FlowLayout` 内部一个 16ms（约 60Hz）定时器驱动所有子项，每个子项存"位置与尺寸、速度、目标矩形、阻尼比"：

```
a = ω²(target − x) − 2ζω·v        // 半隐式欧拉：先用新速度更新位置
```

| 项 | 取值 |
| --- | --- |
| 角频率 ω | 18 rad/s（首次到位约 180ms，过冲顶点约 245ms） |
| 阻尼比 ζ（拖动重排） | 0.70 → 过冲约 4.6% |
| 阻尼比 ζ（增删卡片、窗口/分栏缩放） | 0.98 → 基本不过冲 |
| 定时器间隔 | 16ms |
| 积分步长 | 单步不超过 1/120s，单帧最多 4 步、最多推进 32ms |
| 停止条件 | 距目标 < 0.5px 且速度 < 5px/s，随后吸附到目标 |

- **目标变化只改目标**：位置与速度都留着，新目标从当前运动接着走，连续拖动不会"停一下再重新加速"。
- **目标掉头时清掉该分量速度**：否则那股还没走完的向外速度会在原位置打颤（占位槽扫过卡片时最明显）。
- **宽度不参与弹簧**：组变宽变窄时它内部的卡片要重新换行，宽度做动画会让卡片在换行临界线上反复横跳（多行组表现为整组颤动）。宽度直接到位，x/y/高仍走弹簧。
- **首次落位直接到位**：新建子项没有可衔接的旧位置，否则启动时全体从原点飞出。
- **隐藏项不参与**：被拖动的卡片没有排布结果，弹簧直接摘掉，重新显示时落到新位置。
- **阻尼按"这一次重排改变了什么"选**：布局矩形尺寸变了或子项数变了 → 0.98（增删卡片、缩放），否则 → 0.70（拖动重排）。每个弹簧记住自己启动时的阻尼比，飞行途中不会被下一次重排改掉。
- **弹簧是几何的唯一写入者**：入场/悬停效果都在 `paintEvent` 里缩放，不动几何；落位时给卡片预置占位槽矩形只是给它一个起点，随后由布局按同一矩形接管。

## 4. 拖动周边

- **自动滚动**：由 `src/widgets/DragAutoScroller` 提供，班级表格的拖动排序共用同一套实现（表格在拖动进入时启动、离开或落下时停止）。只有右侧小组列表在拖动时滚动：左栏是纯容器，拖进去就是取消分组，不需要在其中滚动微调，因此左栏不装自动滚动，毛玻璃蒙版才能一直对应冻结的模糊底。三个参数按实例配置：本页卡片信息密度低，最高速度给足 800px/s；表格行矮、密度高，只给 300px/s（约 10 行/秒）。速度单位是像素/秒，所以表格页把视图设成了 `ScrollPerPixel`：item view 默认按整行滚动，滚动条的值是行号，同样的数字会变成“行/秒”。光标进入滚动区上下边缘（本页 60px、表格 80px）内开始滚，速度 = 最高速度 × 深入比例的平方（边缘区里慢、贴边框快），16ms 一步；速度随距离连续变化，起停本身就是缓入缓出。不足 1px 的零头累加到下一拍，否则低速段永远滚不动。
- **拖拽缩略图**：卡片按 1.08 放大，整体压到 190/255 不透明度跟随光标。
- **入场动画**：卡片内部缩放 0.86→1，180ms，不动几何。
- **取消分组蒙版**：铺满左栏栏面（圆角与栏一致）。背景只采样一次：拖入时抓一张列表区快照，用 `QGraphicsBlurEffect` 糊一遍后标上设备像素比存成缓存；整段拖动每帧只贴这张缓存图，不重新采样。表头不在采样范围内，保持清晰。模糊底之上叠一层淡红薄膜（径向：中心 α25、边缘 α0，四角自然收干净），把栏面染成极浅的粉而不压住底下的模糊；再画深红 `#B3261E` 的垃圾桶图标与提示文字，比底色晚 0.25 个进度起淡入。薄膜只负责让毛玻璃立得住（列表区平均色与页面底的亮度差从 2 提到 13），玻璃本身承担列表被打断的提示，文字承担这是删除的语义。先淡入 500ms（OutCubic）、收起 300ms（InCubic）。列表内容或面板尺寸变化后缓存作废，下次显形时重新采样。
