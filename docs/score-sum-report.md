# 积分求和导出报告（HTML）

> 实现位置：`src/core/ScoreSumReport.cpp`。导出入口与排序配置见 [structure.md](structure.md) 第 4.5 节。
> 可视化参考稿：`references/template/积分求和模板个人.html` 与 `积分求和模板小组.html`（不在版本管理内，改样式时可直接在浏览器里对照）。

## 1. 核心目的

把选中的积分记录求和后，写出一份**单文件静态 HTML**，用于大屏投屏或投屏截图：

- **一屏看全班**：1920px 宽屏下尽量塞进更多学生。同样的数据量，卡片网格比传统 `<table>` 布局的信息密度高约 5–6 倍。
- **零依赖**：没有脚本、没有外部资源，CSS 全部内联在 `<style>` 里，双击就能用浏览器打开，长期存档也不会失效。
- **分数是主角**：分数使用最大字号与正/负/零三色，姓名与编号降为配角，远距离一眼可辨。

因此它**不是打印报表**，也不追求像素级规整的行列对齐；它的目标读者是三米外的观众。

## 2. 为什么这样设计

### 2.1 为什么用 flex 卡片而不是表格

表格每行一个学生、行高固定、列宽受约束，宽屏下会留下大片空白；flex 卡片把每个学生压成一个小块后自动换行，密度随屏宽自然上升。表格方案里的斑马纹与 `hover` 高亮也随之取消——大屏展示既没有鼠标交互，也没有逐行阅读长表格的场景。

### 2.2 两套设计语言（个人 / 小组）

两套模板只共享色板与字号层级，圆角策略各自独立：

- **小组：锐利卡片系统**。`.group-card`、`.stat-item` 一律 `border-radius: 0`；唯一的圆角留给排名胶囊 `.group-rank-badge`（`50px`，淡蓝底 + 淡蓝描边 + 蓝字），让「第几名」成为视觉焦点。
- **个人：圆润条目系统**。`.student-item` 使用 `border-radius: 6px`——介于零圆角和排名胶囊之间；个人条目之间需要柔和的间隔感，也不存在需要强调的胶囊元素。

排名胶囊在小组模式下**始终显示**：无论按总分还是按组号排序，都先算出名次再按所选规则重排。

卡片表头从左到右是「排名胶囊 → 组名 → 总分」，总分由 `justify-content: space-between` 推到最右侧；个人条目内部是「编号 → 姓名（`flex: 1` 占满中段）→ 分数 + 单位」：

```text
[#1]  1组                          总分 1024     ← 小组卡片表头
[编号]  姓名                        700 分       ← 个人条目
```

### 2.3 关键 flex 参数与它们的由来

| 参数 | 为什么必须是这个值 |
| --- | --- |
| `.stat-item { flex: 1 0 auto }` | `shrink = 0` 是最关键的一项：空间不足时**触发换行而不是压缩内容**，这是布局不崩的最后防线；`grow = 1` 让每行填满卡片宽度，代价是末行只剩一名学生时那一项会被拉伸——这是刻意保留的取舍：宁可个别条目变宽，也要整张卡片的行边缘保持整齐 |
| `.group-card { flex: 1 1 auto; min-width: 300px }` | 卡片在行内平分剩余空间；`min-width` 防止卡片被挤到不可读 |
| `.student-item { flex: 0 0 200px }` | 个人条目没有「组」这层嵌套：若允许 grow，最后一行的条目会被拉宽，与其它行的分数列错位。固定 200px 牺牲末行饱满度，换取全局网格整齐 |
| `.student-name` 的 `nowrap + hidden + ellipsis` | 超长姓名按 200px 截断，不撑破布局 |
| `font-variant-numeric: tabular-nums` | 数字等宽，分数才能在同一屏里上下对齐成一列 |
| 字号层级 1.8 / 1.55 / 1.2 / 1rem | 总分（`.group-total`）> 个人分数（`.stat-number` / `.student-score`）> 姓名 > 编号；统一用 `rem`，缩放一致 |
| `.groups-row` 用 `gap: 10px`、`.students-grid` 用 `gap: 8px` | 小组卡片更重、需要更大间隔；个人条目更密，8px 在清晰度与密度间取平衡 |

### 2.4 维护禁忌

- **不加 `hover` 与过渡动画**：纯展示页，动画只是性能负担与视觉干扰。
- **不用 media query 调字号**：自适应靠 `flex-wrap` 换行实现，不靠强行缩小字号。
- **不删 `white-space: nowrap`**：`.stat-head`、`.stat-number`、`.group-total` 上它是防崩坏的最后一道保险。
- **不给 `.stat-item`、`.group-card` 加圆角**：零圆角是刻意为之，唯一的圆角属于排名胶囊。
- **不让小组总分与个人分数共用字号**：`.group-total`（1.8rem）与 `.stat-number`（1.55rem）是两级不同的视觉权重。

## 3. 学生编号

编号是可选内容，由 `SortSettings::showStudentNumberFlag` 控制。关闭时**直接不生成** `<span class="student-no">`，姓名自动左移占满空间，布局无需任何额外调整。启用时显示为深蓝色 `#2563b0` 的 1rem 文本，位于姓名之前。

## 4. 兼容性

`gap` 用于 flexbox 需要 Chrome 84 及以上。Windows 7 能安装的最后一版 Chrome 是 109，正常够用；更老的浏览器上 flex 子项之间的间距会失效、元素紧贴。此风险已知，**不做 `margin` 降级处理**。

## 5. 共享色板

| 用途 | 颜色 | 出现位置 |
| --- | --- | --- |
| 页面背景 | `#e8ecf1` | `body` |
| 条目 / 卡片背景 | `#f3f5f7` | `.student-item`、`.group-card` |
| 条目描边 | `#e8eaef` | `.student-item`、`.stat-item` |
| 正分 / 负分 / 零分 | `#15803d` / `#dc2626` / `#6b7280` | `.positive-number`、`.negative-number`、`.zero-number` |
| 学生编号 | `#2563b0` | `.student-no` |
| 姓名 | `#1e293b` | `.student-name`、`.stat-head` |
| 单位字（分） | `#94a3b8` | `.score-unit`、`.stat-unit` |
| 排名胶囊 | 底 `#ebf5fb`、描边 `#c5ddf5`、字 `#3498db` | `.group-rank-badge` |
| 页面标题 | `#1a1a2e` | `.page-title`（仅个人模式有页面标题） |

三个分数色都按 4.4:1 以上的对比度挑：投影仪与环境光会明显吃掉对比度，浅灰的零分（2.3:1）在幕布上几乎看不见。唯一刻意保持低对比的是单位字「分」（`#94a3b8`，2.35:1）——它是次要信息，不需要抢读数。
